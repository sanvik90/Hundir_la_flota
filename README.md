🚢 Hundir la Flota

Juego de Hundir la Flota desarrollado en Python.

Requisitos

Python 3

NumPy

Cómo ejecutar

Clona este repositorio.

Instala NumPy:

pip install numpy

Ejecuta el archivo principal:

python main.py

Características

Tableros de 10x10.

Barcos colocados aleatoriamente.

Turnos de jugador y máquina.

Disparos, aciertos y fallos.

Condiciones de victoria y derrota.
